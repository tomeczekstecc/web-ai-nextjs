# Implementation Plan: Custom App-Scoped 404 Page

**Branch**: `016-custom-404-page` | **Date**: 2026-05-21 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `specs/016-custom-404-page/spec.md`

## Summary

Add two `not-found.tsx` files: one inside `src/app/(app)/` (wrapped automatically by AppShell,
visible only to authenticated users) and one at `src/app/` (global public fallback, wrapped in
AuthShell). Both pages display a minimal centred 404 block — large muted number, Polish heading,
description, single CTA — using only existing design tokens and components.

## Phase 0 — Research

All decisions resolved. See [research.md](./research.md).

Key findings:
- `(app)/not-found.tsx` is wrapped by `(app)/layout.tsx` → AppShell renders automatically
- AppShell redirects unauthenticated users → app-scoped 404 is implicitly auth-gated
- Root `not-found.tsx` reuses `AuthShell` (no new layout code)
- Both files are server components (no `'use client'`)
- HTTP 404 status set automatically by Next.js

## Phase 1 — Design & Contracts

### Authenticated 404 — `src/app/(app)/not-found.tsx`

```
Layout:   (app)/layout.tsx → AppShell (sidebar or top-nav)
Shell:    flex flex-1 items-center justify-center
Block:    flex flex-col items-center gap-4 text-center px-4
Content:  - Large muted "404" (text-8xl font-bold text-muted-foreground)
          - Heading: "Nie znaleziono strony" (text-2xl font-semibold)
          - Description: "Strona, której szukasz, nie istnieje lub została przeniesiona."
            (text-muted-foreground max-w-sm)
          - Button: "Przejdź do pulpitu" → /dashboard
            (variant="default", nativeButton={false}, render=<Link href="/dashboard" />)
Metadata: title: "Nie znaleziono strony", robots: { index: false }
```

### Public 404 — `src/app/not-found.tsx`

```
Layout:   app/layout.tsx (root — fonts, ThemeProvider only)
Shell:    <AuthShell title="Nie znaleziono strony" description="Strona, której szukasz...">
Content:  - Large muted "404" (text-8xl font-bold text-muted-foreground, mb-2)
          - Button: "Zaloguj się" → /auth/sign-in
            (variant="default", full width, nativeButton={false}, render=<Link />)
Metadata: title: "Nie znaleziono strony", robots: { index: false }
```

### Contracts

No new API contracts. No backend interaction. No new env vars.

### Theme & Responsiveness

- Both pages use CSS variables (`text-muted-foreground`, `bg-background`) — light/dark automatic.
- `max-w-sm` on description prevents line overflow on wide screens.
- `px-4` ensures safe margins on 320px viewports.
- `text-8xl` scales with viewport; no fixed pixel sizes.
